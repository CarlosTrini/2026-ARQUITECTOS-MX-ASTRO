# Arquitectos MX

Sitio web de un despacho de arquitectos en CDMX.

Cuenta con publicaciones de arquitectura, página de proyectos y servicios que ofrece el despacho.

![alt text](/public/images/portada.png)


## Sitio desplegado en netlify
> https://despacho-arquitectos-mx.netlify.app/

## ¿Qué se uso durante su desarrollo?

- Astro
- TailwindCSS
- lucide-astro
- react
- react-components
- Typescript
- Markdown (.md) Para el contenido de los post y proyectos
- picsum para todas las imagenes del sitio




## ¿Qué páginas contiene?

- Página de index ( https://despacho-arquitectos-mx.netlify.app/ )
- Página de proyectos (https://despacho-arquitectos-mx.netlify.app/proyectos)
- Página de servicios (https://despacho-arquitectos-mx.netlify.app/servicios)
- Página de proceso (https://despacho-arquitectos-mx.netlify.app/proceso)
- Página de equipo (https://despacho-arquitectos-mx.netlify.app/equipo)
- Página de blog (https://despacho-arquitectos-mx.netlify.app/blog)
- Página de contacto (https://despacho-arquitectos-mx.netlify.app/contacto)

- Página dinámica de proyectos (https://despacho-arquitectos-mx.netlify.app/proyectos/casa-cantera/) (casa-cantera = slug del proyecto)
- Página de dinámica artículos (https://despacho-arquitectos-mx.netlify.app/blog/como-elegir-el-terreno-ideal/) (como-elegir-el-terreno-ideal = slug del artículo)
